# Генераторы и обработка данных на Python

## Описание проекта
Проект содержит набор утилит для обработки и анализа данных, реализованных как генераторы, итераторы и декораторы. Основные компоненты включают инструменты для работы с коллекциями, сортировки данных, измерения времени выполнения и обработки вакансий.

## Структура проекта
```
project/
├── field.py          # Генератор для работы со словарями
├── gen_random.py     # Генератор случайных чисел
├── unique.py         # Итератор для уникальных значений
├── sort.py           # Утилиты сортировки
├── print_result.py   # Декоратор для вывода результатов
├── cm_timer.py       # Контекстные менеджеры для замера времени
├── process_data.py   # Обработчик данных вакансий
└── requirements.txt  # Зависимости
```

### Модульное тестирование
**Назначение**: Обеспечение качества кода через автоматизированное тестирование.

**Реализации**:
1. **TDD подход** (test_field.py, test_unique.py, test_sort.py):
   - Тестирование генератора field (извлечение значений из словарей)
   - Тестирование итератора Unique (фильтрация дубликатов)
   - Тестирование утилит сортировки (корректность сортировки по модулю)

**Пример TDD теста**:
```python
def test_field_single_arg():
    data = [{'a': 1, 'b': None}, {'a': 2, 'b': 3}]
    result = list(field(data, 'a'))
    assert result == [1, 2]
```

2. **BDD подход** (field.feature, unique.feature):
   - Описание поведения на языке Gherkin
   - Реализация шагов в Python

**Пример BDD сценария**:
```gherkin
Feature: Unique iterator
  Scenario: Filter duplicates with ignore_case
    Given input data ["a", "A", "b"]
    When process with ignore_case=True
    Then result should be ["a", "b"]
```

3. **Mock-объекты** (дополнительно):
   - Тестирование взаимодействия между компонентами
   - Изоляция тестируемых модулей

**Пример Mock-теста**:
```python
def test_process_data_with_mock(mocker):
    mock_json = mocker.patch('json.load')
    mock_json.return_value = [{"name": "test"}]
    
    result = f1('dummy_path')
    assert "test" in result
```

## Технологии тестирования

### TDD Framework (pytest)
- Тестирование отдельных функций и классов
- Параметризованные тесты
- Фикстуры для подготовки данных

### BDD Framework (behave)
- Тесты на естественном языке
- Шаги реализованы на Python
- Интеграция с pytest

### Mock-объекты (unittest.mock)
- Замена внешних зависимостей
- Проверка вызовов функций
- Тестирование исключительных ситуаций

## Требования
- Python 3.6+
- Для тестирования:
  - pytest
  - behave
  - pytest-mock (для mock-тестов)
- Указать в requirements.txt:
```
pytest>=6.0
behave>=1.2
pytest-mock>=3.0
```

## Особенности реализации тестов
- Изолированное тестирование каждого компонента
- Покрытие основных и граничных случаев
- Четкое разделение тестов на модульные (TDD) и поведенческие (BDD)
- Возможность интеграции в CI/CD pipeline
- Гибкая настройка тестового окружения

## Пример запуска тестов
```bash
# Запуск модульных тестов
pytest lab_05_TDD

# Запуск BDD тестов
behave steps/process_data_steps/
```

Проект демонстрирует комплексный подход к разработке - от реализации базовой функциональности до обеспечения качества через автоматизированное тестирование с использованием современных методик (TDD, BDD) и инструментов.
