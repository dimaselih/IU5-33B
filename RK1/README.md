# Программа для работы с библиотечной системой

## Описание проекта
Проект реализует систему учета книг в библиотеках с двумя типами связей:
- Один-ко-многим (книга принадлежит одной библиотеке)
- Многие-ко-многим (книга может находиться в нескольких библиотеках)

Система позволяет выполнять аналитические запросы для получения информации о книгах и библиотеках.

## Структура проекта
```
library_system/
```

## Классы данных

### 1. Класс `Book` (Книга)
```python
class Book:
    """Книга"""
    def __init__(self, id, title, author, year, lib_id):
        self.id = id
        self.title = title
        self.author = author
        self.year = year  # Год издания
        self.lib_id = lib_id  # ID основной библиотеки
```

### 2. Класс `Library` (Библиотека)
```python
class Library:
    """Библиотека"""
    def __init__(self, id, name):
        self.id = id
        self.name = name
```

### 3. Класс `BookLib` (Связь книг и библиотек)
```python
class BookLib:
    """
    'Книги в библиотеке' для реализации 
    связи многие-ко-многим
    """
    def __init__(self, lib_id, book_id, count):
        self.lib_id = lib_id
        self.book_id = book_id
        self.count = count  # Количество экземпляров книги в библиотеке
```

## Реализованные запросы

### Запрос B1
Список книг, название которых начинается с заданной буквы (в примере - 'С')
```python
result = [item for item in one_to_many if item[0].startswith('С')]
```

### Запрос B2
Список библиотек с минимальным годом издания книг
```python
min_years = {}
for title, author, year, lib in one_to_many:
    if lib not in min_years or year < min_years[lib]:
        min_years[lib] = year
sorted_libs = sorted(min_years.items(), key=lambda x: x[1])
```

### Запрос B3
Список всех связей книг и библиотек, отсортированный по названиям книг

```python
sorted_books = sorted(many_to_many, key=lambda x: (x[0], x[1]))
```
