# Программа для работы с геометрическими фигурами

## Описание проекта
Проект реализует систему классов для работы с геометрическими фигурами (прямоугольник, квадрат, круг) с возможностью:
- Хранения характеристик фигур (размеры, цвет)
- Вычисления площадей
- Вывода информации о фигурах

## Требования к окружению
1. Python 3.x
2. Рекомендуется использовать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # для Linux/Mac
   venv\Scripts\activate  # для Windows
   ```
3. Установите необходимые пакеты:
   ```bash
   pip install colorama  # пример внешнего пакета
   ```

## Реализованные классы
### 1. Базовые классы
- **Figure** (абстрактный класс):
  - Содержит абстрактный метод `area()` для расчета площади
- **Color**:
  - Хранит цвет фигуры как свойство (property)

### 2. Классы фигур
Все классы фигур:
- Наследуются от базового класса Figure
- Реализуют метод `area()`
- Содержат поле `name` с названием фигуры
- Имеют метод `__repr__` для красивого вывода информации

#### Конкретные фигуры:
1. **Rectangle** (Прямоугольник):
   - Параметры: ширина, высота, цвет
2. **Circle** (Круг):
   - Параметры: радиус, цвет
   - Использует math.pi для расчета площади
3. **Square** (Квадрат):
   - Наследуется от Rectangle
   - Параметры: длина стороны, цвет

## Использование
Пример использования в main.py:
```python
from lab_python_oop.rectangle import Rectangle
from lab_python_oop.circle import Circle
from lab_python_oop.square import Square
from colorama import Fore  # пример использования внешнего пакета

def main():
    # Создание фигур (N - номер по списку группы)
    N = 5  # пример значения
    figures = [
        Rectangle(N, N, "синий"),
        Circle(N, "зеленый"),
        Square(N, "красный")
    ]
    
    # Вывод информации о фигурах
    for figure in figures:
        print(figure)
    
    # Демонстрация работы внешнего пакета
    print(Fore.RED + "Пример использования colorama" + Fore.RESET)

if __name__ == "__main__":
    main()
```

## Особенности реализации
1. Все классы находятся в отдельных файлах пакета lab_python_oop
2. Реализована проверка корректности входных данных
3. Используются:
   - Абстрактные методы (для расчета площади)
   - Свойства (property) для цвета
   - Наследование (квадрат → прямоугольник → фигура)
4. Подключен внешний пакет (colorama в примере)
