# Программа для решения биквадратных уравнений

## Описание программы
Эта программа предназначена для вычисления действительных корней биквадратного уравнения вида:  
**Ax⁴ + Bx² + C = 0**

## Особенности реализации
- Написана на Python как консольное приложение
- Поддерживает два способа ввода коэффициентов:
  - Через параметры командной строки
  - Интерактивный ввод с клавиатуры
- Обрабатывает некорректный ввод данных
- Вычисляет дискриминант и действительные корни уравнения

## Требования
- Python 3.x

## Использование
### Вариант 1: Запуск с параметрами командной строки
```
python bicquadratic.py A B C
```
где A, B, C - коэффициенты уравнения

### Вариант 2: Интерактивный ввод
Если коэффициенты не указаны в командной строке, программа запросит их ввод:
```
Введите коэффициент A: 
Введите коэффициент B: 
Введите коэффициент C: 
```

## Обработка ошибок
Программа проверяет корректность введенных данных:
- Коэффициенты должны быть действительными числами
- При некорректном вводе программа запрашивает повторный ввод

## Дополнительные задания
1. Реализация в разных парадигмах:
   - `bicquadratic_procedural.py` - процедурный подход
   - `bicquadratic_oop.py` - объектно-ориентированный подход

```
> python lab_01_OOP.py 1 -5 4
```
